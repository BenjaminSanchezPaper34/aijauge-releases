# AIjauge — téléchargements et mises à jour

Jauge d'usage des forfaits d'IA pour Mac, iPhone et Apple Watch. Ce dépôt ne contient que les fichiers de distribution :

- `appcast.xml` : flux de mises à jour automatiques (Sparkle) de l'app Mac.
- Les DMG signés et notarisés sont dans les [releases](../../releases).

Le code source n'est pas public. AIjauge est un logiciel indépendant, sans lien avec Anthropic ; Claude est une marque d'Anthropic, PBC.
