Un problème

Écrivez à contact@paper34.fr : la réponse arrive sous 48 heures ouvrées. Depuis l'app (Réglages sur l'iPhone, menu ⋯ sur le Mac), le mail part avec la version et l'appareil déjà remplis. Vous pouvez aussi le signaler publiquement.

Comment on choisit

Chaque semaine, les idées et les problèmes sont triés par nombre de votes. Les problèmes passent avant les nouveautés ; parmi les idées, les plus demandées d'abord, si elles respectent ce qui fait AIjauge : lecture seule, aucun identifiant qui quitte le Mac, une interface sobre. Une idée retenue est marquée « prévu », puis « livré » avec la version qui l'apporte.
